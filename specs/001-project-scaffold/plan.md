# Implementation Plan: Initial Project Scaffold

**Branch**: `001-project-scaffold` | **Date**: 2026-10-18 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-project-scaffold/spec.md`

## Summary

Establish a bootable, type-safe Expo (SDK 54) + Expo Router + TypeScript skeleton for the
local-first "Pausa" mobile app. The scaffold delivers: a global provider/theme layout with thin
routing, placeholder feature routes, a strict-typed Drizzle + expo-sqlite data layer with the
initial domain tables, and baseline configuration (build profiles, app metadata with deep-linking
scheme and local-notification/database plugins, database tooling, transpiler). Primary requirement:
`FR-001`–`FR-012`; success is a clean strict type check, a bootable app with reachable routes, and
an idempotently initialized local database.

## Technical Context

**Language/Version**: TypeScript 5.x (`strict: true`), React Native 0.81, Expo SDK 54

**Primary Dependencies**: Expo Router v6; Gluestack UI (`@gluestack-ui/themed`, `@gluestack-style/react`);
`react-native-reanimated`; `react-native-svg`; `lucide-react-native`; `react-native-safe-area-context`;
`react-native-screens`; `expo-constants`; `expo-status-bar`; `expo-linking`; `drizzle-orm`; `expo-sqlite`;
`expo-notifications`; `expo-task-manager`; `zod`. Dev: `drizzle-kit`, `babel-plugin-inline-import`.

**Storage**: Local SQLite via `expo-sqlite`, accessed exclusively through Drizzle ORM. Migrations
generated by `drizzle-kit` and bundled as inline `.sql` imports. No key-value storage for domain
entities.

**Testing**: Jest with `jest-expo` preset; `@types/jest` (dev). Initial scope: unit tests for shared
utilities and the DB schema/mappers.

**Target Platform**: Mobile (iOS + Android), Expo managed workflow. Web out of scope for v1.

**Project Type**: mobile-app

**Performance Goals**: App cold start reaching first interactive frame < 3s on a mid-tier device;
navigation transitions at 60fps.

**Constraints**: Offline-capable / local-first; strict type checking with zero errors; privacy —
emotional logs stay on-device; scaffold must boot even if notification permission is denied.

**Scale/Scope**: 7 feature modules; ~8 initial route files; 3 initial local tables; single developer
onboarding target of < 2 minutes to locate the correct destination for new code.

**Structure Decision**: Mobile app with a thin Expo Router layer (`app/`) and all logic under `src/`
with feature modules (`src/modules/<module>/`) plus a shared layer (`src/shared/`), exactly as
mandated by constitution §1.1. Route files import view components from modules; no business logic in
`app/`.
