# Contract: Local Persistence (Drizzle + expo-sqlite)

The single sanctioned persistence interface for domain entities (constitution §3). No key-value
storage for entities.

## Modules

- `src/shared/db/schema.ts` — Drizzle table definitions (`user_profile`, `smoke_logs`,
  `supply_inventory`). Exports table objects; shared row types live in `src/shared/types/` when
  cross-module.
- `src/shared/db/client.ts` — opens the SQLite database and exports the typed Drizzle instance.

## Exposed contract

```ts
// src/shared/db/client.ts
import type { ExpoSQLiteDatabase } from 'drizzle-orm/expo-sqlite';
import type * as schema from './schema';

export const db: ExpoSQLiteDatabase<typeof schema>;

// Startup initialization (called once from app/_layout.tsx)
export function useDatabaseInitialized(): { ready: boolean; error: Error | null };
```

## Requirements

- **R-DB-1**: The client MUST open the local SQLite database exactly once and expose a typed Drizzle
  instance.
- **R-DB-2**: Migrations MUST be generated by `drizzle-kit generate` and bundled as inline `.sql`
  imports; they MUST be applied idempotently on startup.
- **R-DB-3**: Initialization MUST be idempotent — running it against an existing database MUST NOT
  destroy data.
- **R-DB-4**: All historical log getters MUST return records ordered DESC by timestamp
  (code-rules §11), e.g.:

  ```ts
  db.select().from(smokeLogs).orderBy(desc(smokeLogs.createdAt))
  ```

- **R-DB-5**: No domain entity MAY be persisted via AsyncStorage or any non-Drizzle store.
- **R-DB-6**: Types MUST be explicit; `any`/`unknown` are forbidden (code-rules §1).

## Error contract

- Initialization failure surfaces an error state to the caller; the app MUST not render routes against
  an uninitialized database (`FR-008`).

## Privacy contract

- Emotional data (`smoke_logs.reason`, `notes`) is local-only and MUST NOT be included in any sync
  payload (constitution §3, code-rules §12).
